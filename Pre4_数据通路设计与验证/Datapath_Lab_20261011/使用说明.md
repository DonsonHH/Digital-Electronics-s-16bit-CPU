# Datapath Lab 使用说明

双击 `index.html` 即可离线打开。原来 `diagrams/Datapath_Continuous_20261010/Datapath_Trace_Viewer.html` 入口也已更新为同一版本。

## 最直接的操作

1. 页面默认以可读字号显示 PC 模块。左侧选择模块，或直接点击画布上的节点，会自动定位放大；右侧说明它做什么、输入输出如何使用，并可切换到 RTL 原文。
2. 点击一条线：整条信号及分支高亮，右侧列出来源和全部接收端。点“只定位”可沿线移动而不丢失高亮。
3. 遇到寄存器：先看捕获表达式、valid/fault/enable 条件，再点“继续追踪 Q”。
4. 切换左侧 Walkthroughs，可分步阅读 STR、LDR、ADD、CMP/JZ、load-use 和故障 STR 的完整逻辑。

## 新增的聚焦效果

- 点模块：当前模块有绿色边框，直接输入来源与输出接收模块保持明亮；其余模块变灰、淡化。不会因为共用 `clk/rst` 就把其他负载都当成这个模块的下游。
- 点线路：突出整条信号、来源和全部接收端。选中 `clk/rst` 本身时，同样会完整显示它的所有真实接收端。
- 明暗关系在总览、放大视图和缩略图中一致。总览中的选中线路保持 1.6px 线宽，便于追踪。
- 淡化不是禁用，仍然可以直接点击其他模块或线路切换。`Clear` 退出聚焦；返回和导入进度会恢复对应的聚焦关系。
- 模块聚焦只收窄模块的高亮范围，未裁剪共享输入的物理分支；点击该输入线即可查看完整扇出。高亮不表示当前指令已选择所有 MUX 输入。

工具栏支持返回、适配和完整总览；缩略图可快速定位。搜索支持模块名、中文名称、信号别名及位范围，如 `alu`、`寄存器`、`im_addr`、`wb_data[15:0]`。搜索 `STR` 可直接开始讲解。

总览用于找模块，因此只显示简洁的模块名称；放大后恢复全部端口与寄存器字段。所有线路一直保留。窄屏遇到较宽或较长的模块时，可拖动画布看另一侧，不再为了塞进窗口而把文字缩得很小。

“顺着一条线”浮层和四角冗余小字已经移除。正文约 16px，常用控件与辅助文字约 14–15px；点击聚焦后的端口文字至少约 15px。选中线路的粗细也已减轻。

右侧星号收藏最多 8 条信号。保存进度会下载 JSON，可在同一 CPU 源码版本中导入恢复。Export SVG 导出完整连线图，并清除临时高亮和淡化。

快捷键：`/` 搜索，`F` 适配选择，`O` 总览，讲解中 `← / →` 前后步骤。小窗口通过“浏览模块 / 电路画布 / 节点详情”切换。

## 阅读规则

- 实心点是相连分支，跨线桥只是交叉。
- 反向摆放的寄存器 D 在右侧、Q 在左侧。G 表示带资格的赋值，E 表示捕获使能。
- 高亮表示物理连接，不代表所有分支在当前指令中同时生效。
- 指令讲解里的数值是教学示例；一个讲解步骤不等于一个时钟周期。网页没有重新执行 CPU 仿真。
- 全部连线来自原有已核对的图：37 个功能块/寄存器组、134 个信号网络、227 个接收端。组合控制仍按功能分组，CLA 内部位级门电路没有在此图全部展开。
