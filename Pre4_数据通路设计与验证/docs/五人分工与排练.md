## 常见答辩问题

**Why does successful STR have no WB action?**

"STR completes the memory write in MEM. Its WB slot is a bubble, while other instructions still advance one stage per cycle. A faulting STR keeps a WB stop token instead."

**Is the memory an asynchronous simulation shortcut?**

"No. Both memories register the read result on the active clock edge and hold it when disabled. Their outputs form the corresponding logical pipeline data boundaries."

**Why can JZ use CMP before Z write-back?**

"The control word identifies a valid older CMP candidate. JZ selects the newest candidate from MEM, then WB, then architectural Z."

**Does your hand-written CLA run faster on the FPGA?**

"The source and RTL analysis prove the two-level lookahead structure. Speed needs a fair implemented timing comparison. Our ten-nanosecond OOC synthesis estimate still has negative slack."

**Did you test every 16-bit arithmetic input?**

"No. We report the exact pattern, directed and random ranges. CLA4, the decoder, immediate extension and flag transitions have their stated exhaustive spaces; the large 16-bit spaces are bounded regressions."
