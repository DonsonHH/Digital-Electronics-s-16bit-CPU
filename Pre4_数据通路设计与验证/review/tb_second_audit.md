# Pre4 测试平台独立二次审计

审计日期：2026-10-09。依据 CPU v1.4 设计规格以及交付目录的 RTL/TB。审计范围为行为仿真的参考模型、计数范围、边沿调度、故障和复位断言，以及新增独立程序级压力测试；不宣称完成综合网表、布局布线、板级或全 CPU 状态空间形式证明。

## 结论

没有在现有生产 RTL 中发现由本次审计或新增压力测试复现的功能缺陷。原有 128 个程序案例、16 次复位探针以及单元计数的含义一致；大规模 16 位算术测试不能称为完整输入穷举。

发现并补足的主要覆盖缺口是：原 100 个随机程序只有直线控制流、固定合法基址和非负访存偏移。新增 `tb_stress.sv` 不复用原 `reference()`，采用逐完成事件的 ISA 记分板，真实运行 Vivado 2025.2 通过 4,696 个附加案例。

同时发现两处原 TB 的稳健性增强点：原故障检查对停止边沿很严格，但不是每个案例都直接核对故障 token 的 `w_pc`；原三个 `$fopen` 输出没有检查打开成功。已交由主审查者增强，修正后的最终结果以交付复核记录及新日志为准。

## 原 TB 逐项检查

### 参考模型独立性

`tb_datapath.reference()`按 Opcode 直接解释 ISA，不调用 DUT 的译码器、ALU、转发单元或流水控制结果。加法 C 用扩宽整数和大于 65535 判断；减法 C 用无符号 `a>=b`；V 用精确有符号整数是否越过 −32768..32767，独立于 DUT 的符号位布尔公式。访存 EA 先模 65536 再检查 0..255，避免 FFFF 被误当作有符号 −1 或截低位后漏报。

参考模型读取 DUT 的 IM/DM 仅用于获取测试装载的初值，并非借用 DUT 的计算结果。生成的预期事件包含 PC、RF 目的、数据、访存地址和标志；事件顺序按老 WB 在前、成功 MEM STR 在后处理。最终逐一比较全部 RF、Z/C/V 和 256 字 DM，成功 STR 的 WB bubble 不计成第二次完成。

局限：两个模型仍来自相同规格，无法消除规格本身错误的共同来源风险。生产模型预先计算整段程序，新增模型在每次实际完成时独立解释下一条指令，提供不同实现形式的交叉检查。

### 调度与 race

复位和测试装载在下降沿操作；核心状态在上升沿用非阻塞赋值更新。TB 在上升沿、NBA 前读取当前 WB/MEM 的输出资格，在 `#1` 后检查锁存后的状态，不依赖两个 `always` 块执行先后。`#1`是仿真采样分隔，不是器件时序/Fmax 证据。

RF 初值及 flags 的层次化预置只属于定向测试夹具，不代表 ISA 能直接写任意 16 位立即数；正常基准程序用 MOV 初始化并从复位状态运行。

### 故障停止不是只检查末状态

原 TB 的 `pre_w_fault`在上升沿 NBA 前采样有效 WB 故障 token，并断言该 token 处于 DRAIN_FAULT、无 RF/Z/CV 写入资格。随后 `#1`断言 fault=1、halted=0、mode=FAULTED、所有流水 valid=0；若没有有效 WB 停止 token 就提前停止，立即失败。

T05/T17 在 MEM 故障发生拍检查完整 EA、老 WB 资格，并在 `#1`检查该故障 token 已到有效 WB、且 `w_pc=0001`。T16 断言老 MEM 故障战胜年轻 EX HALT；T18a 检查 pc=0100 的正确路径 fetch_fault 到达 X/M，T18b 证明年轻 fetch_fault 被分支取消。停止后还观察 3 个边沿，禁止新的访问或写入。

增强建议是所有 `pre_w_fault` 都核对 `w_pc===ref_pc`。原参考模型发生故障时停止在其 PC，不再递增，因此可直接作为故障 token 年龄/地址期望值。

### 断言不会依靠 guard 未到而空过

原 TB 对关键 T05/T07/T08/T16/T17/T18 与附加相关案例有 required/seen witness 位图。用例结束核对每个必需场景确实发生，避免条件断言未命中但报告 PASS。附加记分板不依靠预先猜测周期：每个有效完成事件更新参考状态，每个边沿无条件比较全部架构状态，并精确检查 WB 停止边沿。

### 复位覆盖

16 个探针包括正常序列的 phase=0..12 和故障序列的 phase=4..6，覆盖 RUN、DRAIN_HALT、HALTED、DRAIN_FAULT、FAULTED 下的复位。RF/flags 使用非零夹具使清零可观察；在 MEM 即将 STR 的边沿验证复位禁止写入；已完成 STR 后验证 DM 内容保留。该范围不是所有 CPU 状态下的复位穷举，也没有随机异步复位测试，因为本规格定义高有效同步复位。

## 原单元计数核对

| 项目 | 实际计数与边界 |
|---|---|
| CLA4 | 16×16×2=512，全部二进制输入，sum/cout/P/G及 cin 独立性 |
| CLA16 / ADD-SUB | 每项 (65536×4+20000+6)×2=564300 次；B为四种模式加随机及定向，不是所有 A/B |
| ALU | (65536×4+20000+6)×8=2257200 次；包括5合法、3非法内部选择，非完整 2^35 空间 |
| Decode | 65536 指令字全部检查控制、字段、实际 use 掩码 |
| Immediate | 256×2=512，全部 imm/mode |
| Flags | 8旧态×2rst×4写掩码×8输入=512；建立旧态的边沿不计 |
| RF | 65536×4写事务＋16读地址组合＋1复位事务=262161，不是所有旧态及控制组合 |
| PC | 65536 个顺序旧态＋3代表优先级=65539，不是所有控制组合 |
| Target | 7个PC×256个imm×2模式=3584，不是完整PC×imm空间 |

计数是执行检查的次数，四种 B 模式可能重合，因此不是唯一 A/B 对数量。精确全空间规模 CLA16/ADD-SUB 为 2^33，完整 ALU 为 2^35；CPU级程序回归不替代这些单元全空间要求。

## 新增独立压力测试

工具：Vivado/XSim 2025.2，单时钟 #5 翻转用于行为仿真。可重复随机初始 seed：`A9D41009`，xorshift32。参考状态独立存于 `image/memory/rf/z/c/v/rpc`，不从 DUT 获取期望计算结果。

每个上升沿先核对老 WB 完成，再核对年轻成功 MEM STR。正常 WB 检查下一指令 PC、写掩码、HALT/load 类型、RF 目的和写值；遇到 WB 故障 token 时，直接按 ISA 判定参考 PC 的下一条指令确实应非法、访存越界或取指越界，并核对故障 PC。随后 `#1`比较全部 RF、Z/C/V 和 256 字 DM，断言停止正好在相应 WB token 结束边沿，且流水为空。每例有 1024 周期超时及 3 拍停止保持检查。

| 类别 | 案例数 | 精确约束 |
|---|---:|---|
| signed EA 边界 | 3584 | 256 种 imm8×基址0000/0001/007F/0080/00FF/0100/FFFF×LDR/STR；访问前老 ADD 必须完成，覆盖合法、越界及模地址回绕 |
| 有界循环 | 100 | 每例1..31次；合法 R3=128，全部8位偏移采样；STR→LDR→load RAW→ADD→STR→SUB→CMP→JZ/JUMP；错误路径放保留 F 和访存指令 |
| 随机控制流 | 500 | 64 字随机程序＋HALT；JUMP/JZ目标只向前，保证有限；Rd=0..2、内存基址R3=32、offset=−32..31；随机算术、逻辑、比较、立即数、源相关、未使用字段及全部8个初始 flags 状态 |
| JZ 偏移边界 | 512 | PC=0与128，各256种 imm8；−1的自环特例设Z=0，不声称验证 taken 无限自环停止；其他偏移设Z=1，检查相对目标及越界 |

真实恢复后完成输出：

```text
STRESS_PASS cases=4696 memory_offset_boundary=3584 loops=100 random_control_flow=500 branch_offset_edges=512 completed=33134 fault_tokens=1408 taken=3636 not_taken=2155 legal_opcodes=14/14 failures=0 seed=A9D41009
```

`taken`含 JUMP 与 taken JZ，不是仅条件分支数；`completed`不含故障指令 token，故障 token 单独计 1408。14 种合法 Opcode 均实际完成。初始 flags 的 8 个组合有独立 coverage 位图和最终必达断言。已生成 `stress_results.json`，若输出文件无法打开，TB 会 Fatal。

另外用独立整数枚举核算故障分类：7 个基址各有 128/127/1/0/127/128/129 个越界 offset，共640×LDR/STR两种=1280 个访存故障；PC0/128 的 JZ 边界各有127/1个取指故障，共128个；合计1408，与实测故障 token 完全一致。有界循环和向前随机控制流程序均正常 HALT。

## Mutation sanity

只在私有复制 RTL 上分别加入单一故意错误，不修改生产文件；每次重新 xvlog/xelab/xsim，完成后恢复并再次全部通过。恢复的13个 RTL 文件逐文件 SHA256与生产版本一致。

| 故意错误 | 必然捕获的反例 |
|---|---|
| 禁用 C/V 写使能 | `Fatal: write intent EA_0_0_0 pc=00000000`，75ns |
| signed immediate 被零扩展 | `Fatal: unexpected normal WB EA_0_128_0 pc=0001 reference=00000001`，30805ns |
| taken branch不冲刷年轻指令 | `Fatal: spurious/wrong-age fault LOOP_0 actual=0008 expected=00000001`，417445ns |

这是有限的记分板灵敏度检查，不是所有可能错误的变异覆盖证明。故意错误 RTL不纳入交付。私有日志保留用于本次审计溯源。

特别注意：这些 Fatal 中 XSim 仍返回退出码0，故运行器必须同时拒绝日志 Fatal/ERROR、要求本轮 PASS 和新回执。仅 `if errorlevel 1` 还会漏掉负数 Windows NTSTATUS；协调主审查正在修正共享运行脚本及 fresh receipt 校验。

## 剩余限制

新增压力测试扩展了有符号地址和控制流覆盖，没有穷举全部16位寄存器初态、全部程序镜像、所有流水组合或算术输入空间。采用固定一边沿同步 IM/DM，不验证外部可变等待、未知态/X/Z注入、ECC或总线错误，这些不在当前接口契约内。没有综合网表后仿真，也不证明 100MHz 实际实现时序达标。功能通过与尚未完成的时序/板级工作必须继续分开陈述。
