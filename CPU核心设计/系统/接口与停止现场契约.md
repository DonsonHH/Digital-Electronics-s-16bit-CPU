# AC1最小系统接口与停止现场

当前阶段在AC1执行路径之外增加观测，不修改ISA v1.5、流水级、停顿次数、提交顺序或架构副作用边沿。`cpu_system`接收同一时钟域的clk和同步高有效rst；EES-331的异步按键同步及板级I/O属于后续板级顶层。

IM/DM各256×16，INIT_FILE参数在配置/仿真启动时初始化，不在核心reset时重载。程序镜像完整256字、每字4位十六进制；IM空闲字B000，DM未指定字0。有效读请求在采样边沿后更新dout；en=0保持；DM写周期dout保持。DM实际使能来自核心完整16位EA与有效资格，物理地址再取低8位。系统测试只从文件启动，不向DUT内部IM写程序。

核心追加只读WB标签/写入意图、stall/redirect及停止现场端口。WB有效标签包含成功STR、分支、HALT以及故障token，不能等同RF写入或合法退休。RF/flags写使能仍使用原资格表达式；观测信号不反馈执行控制。系统用这些公开写入事件维护4×16的调试影子，提供最终RF结果；这不是增加架构RF读口。系统还保存最近一次成功store地址/数据，提供公开MEM总线事件以核对DM副作用。

停止原因随对应指令在X/M/W传播。被取消标签不产生停止现场；老MEM故障覆盖年轻EX事件。正常或指令故障停止时，在原drain_done边沿消费WB停止token，并锁存stop_pc=w_pc、stop_reason和stop_pc_valid=1；现场保持至reset，不使用PC_fetch。故障token不算合法完成，last_completed_pc只记录合格无故障WB标签，包含HALT与成功STR。

| stop_reason | 含义 | PC有效性 |
|---|---|---|
| 0 | 尚无停止现场 | stop_valid=0 |
| 1 | HALT | WB停止指令自身pc |
| 2 | 正确路径非法Opcode B/F | 故障指令pc |
| 3 | 取指地址越界 | 越界取指标签pc |
| 4 | 数据访存地址越界 | 访存指令pc |
| 5 | 内部控制非法/消费未就绪操作数 | 对应EX故障标签pc |
| 6 | 非法二进制mode进入既有fail-safe FAULTED | stop_pc_valid=0，无可归属指令 |

reset清核心/观测在途状态、RF影子及停止现场，禁止本拍RF/flags/DM写入；已提交DM保留。debug_stall只计实际保持前端的load-use，不计被更高优先级事件取消的请求；debug_redirect是原qualified_redirect。调试影子及最后store记录是附加观测资源，资源报告须包含或明确分列。

系统验收同时核对公开WB事件、有序store事件、最终RF/flags、稳定停止PC/原因、load-use与redirect数及必要周期数。覆盖全14合法Opcode、taken/非taken、错误路径store/非法指令取消、老load/store在HALT前完成、MEM故障覆盖年轻HALT、取指越界、reset保留DM及reset禁止待写store。原因5/6采用明确标注的受控内部注入另检，不声称一般硬件故障容错。
