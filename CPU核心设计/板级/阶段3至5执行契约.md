# EES331板级实现与单变量实验

本轮开发分支feat/ees331-board-performance，基点5dfe09ec153c4807d418efecbf7f2cf3c25d419e；7753502仍为原始归档参考。阶段0至2、Pre1至Pre5和既有attempt保留原字节。AC1执行路径与ISA v1.5作为稳定基线，新增板级文件及实验候选隔离存放，不先改写正式核心。

阶段3采用课程EES-331、xc7z020clg484-1。依据手册PDF第5、7、29至30页核对3.3V Bank、M19的100MHz晶振、L18按键和LED引脚；复位极性须读原理图确认。板级复位同步、上电初始化和JTAG受控复位必须防止未复位取指、重复写入及重载DM。结果通过JTAG调试接口读取RF、标志、停止PC/原因和必要计数；LED只作辅助。完成真实布局布线和setup/hold/脉宽、未约束路径及DRC审查；不以false-path或multicycle掩盖同步数据路径。异步按钮仅对同步器输入使用符合电路性质的例外。实际连接板型须确认后才能烧录。

阶段4固定工具2025.2、100MHz目标、同一板级顶层、RAM映射、调试探针与实现策略。以阶段2代表程序及新增压力程序记录架构结果、动态指令、有效周期、stall/redirect、LUT/FF/BRAM/CARRY和完整实现时序。仿真时间、目标频率推算时间与真实板上计数分别标注；程序时间使用实际受约束且已验收的工作频率。

阶段5先评估前递/操作数MUX的单变量组合候选，要求架构结果及逐拍契约与AC1相同。再隔离评估WB到MEM的STR数据旁路，优先复用m_rd，只在STR数据依赖而基址不依赖时消除相邻load停顿。必须明确未就绪标记、最新生产者优先、blocked_rd、基址、load故障、复位及年龄仲裁；该候选使用单独周期预期，不修改冻结用例来伪造旧周期PASS。每个候选都先验证再在同一板级和实现策略比较；没有收益则保留基线并记录实验结果。

已确认测试边界沿用ISA独立参考、原核心回归与逐拍监视、文件初始化存储及系统公开观测，新增板级复位/计数接口和JTAG结果读取。候选压力测试覆盖相邻/隔一条依赖、多生产者、Rd=Rs、R0、错误路径、停止/故障/reset交叉。硬件故障注入仅为受控仿真，不代表通用容错。每阶段结束先Review；最终更新同一核心Word、图和入口，并按实际证据保留未完成事项。
