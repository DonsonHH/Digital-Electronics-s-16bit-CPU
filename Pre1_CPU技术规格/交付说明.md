## 复现模型

使用Python 3，无第三方依赖。在本目录执行：

```powershell
python .\模型核对\pipeline_model.py
python .\模型核对\extended_checks.py
```

脚本会覆盖各自目录中的同名结果JSON，不会修改PPT、Word或课件。

## 证据边界

周期模型按抽象阶段推进，不实现Verilog事件调度或厂商BRAM。模型中的事件序号与统计属于验证工具，不要求综合进CPU核心。测试发现五种人为删除机制的错误，不代表消除了所有设计错误。随机控制流和访存范围有明确约束；未验证任意拍硬件复位。

课件核对覆盖页面文本、表格、备注和结构，并选择CPU控制图、流水图、加法器及时序关键页进行图像核对；不是对1080页所有图像、习题或模拟电路进行完整认证。扫描教材PDF未完成OCR。附录C对用户提供的建议逐项说明采用、限定采用或不采用的理由。

## 实现前必须落实

1. 确认实际FPGA器件、板卡和工具版本；课堂频率示例不能作为已收敛频率。
2. 锁定IM/DM同步读延迟、输出寄存器及en保持行为，先做存储IP独立Testbench；若变更延迟，必须同步修改流水边界和停顿规则。
3. 依接口实现并验证译码、RF、ALU、PC和流水寄存器；随后加入转发、load-use、CMP至JZ和冲刷。
4. 集成时重点证明STR在MEM写入且WB无动作、HALT排空、较老故障优先、错误路径不写状态、任意拍复位无残留副作用。
5. 最后比较相同约束下的资源、时序与程序运行时间，再决定是否采用候选优化。文档不承诺最高分或最优性能。
